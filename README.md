## Программа

`main.py` вычисляет средний балл набора оценок. Функция `average_score`
возвращает среднее арифметическое; для пустого списка вызывает `ValueError`.
В примере используются оценки `[5, 4, 3, 5]`: сумма 17, количество 4, среднее 4,25.
Для запуска программы сторонние библиотеки не требуются.

```bash
python main.py
```

Фактический результат локального запуска:

```text
Average score: 4.25
```

## Игнорирование служебных файлов

`.gitignore` исключает кэш Python, виртуальные окружения, локальные настройки,
файлы `.env` и результаты проверок. Образец `.env.example` разрешён.
Проверка шаблонов выполнена командой:

```bash
git check-ignore -v --no-index __pycache__/main.pyc .venv/example.txt .env
```

Фактический вывод:

```text
.gitignore:1:__pycache__/	__pycache__/main.pyc
.gitignore:3:.venv/	.venv/example.txt
.gitignore:5:.env	.env
```

## GitHub Actions

Процесс [Python checks](.github/workflows/python-check.yml) запускается при `push`,
`pull_request` и вручную. Используются Python 3.12 и flake8 7.3.0.
Шаги: получение кода, установка зависимостей, проверка стиля, запуск трёх тестов.

Повторение проверок локально:

```bash
python -m pip install -r requirements-dev.txt
python -m flake8 main.py tests
python -m unittest discover -s tests -v
```

**Удалённый запуск пока не подтверждён.** После публикации проекта здесь будет
указана ссылка на фактический успешный запуск во вкладке Actions.
